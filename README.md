# Madhav Ecommerce Sales Dashboard

## Project Overview
This project is an interactive e-commerce sales dashboard created using Microsoft Power BI.

## Tools Used
- Power BI
- Excel
- DAX

## Dashboard Features
- Total Sales
- Total Orders
- Profit Analysis
- Sales by Category
- Sales by Product
- Sales by Region
- Interactive filters and visualizations

## Project Objective
To analyze e-commerce sales data and create an interactive dashboard that helps understand sales performance and business trends.
